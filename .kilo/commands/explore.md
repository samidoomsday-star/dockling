# Explore (Phase 0 only)

1. Read `docs/SPEC.md` Phase 0 and `docs/EXPLORATION_REPORT.md`.
2. Clone or install the upstream project exactly as Phase 0 says; use only free options unless the owner approves spending.
3. Get it running locally. If something fails, read the real error, fix setup (not upstream code), and record problem + fix in the report.
4. Try every feature listed in Phase 0 with safe sample data (owner's own, public-domain, or generated). Record results, timings and output quality.
5. Do NOT write product code, and do NOT change upstream code.
6. Fill every section of `docs/EXPLORATION_REPORT.md`, update `docs/PROGRESS.md`, commit.
7. Stop. Tell the owner the report is ready for review; wait for their decision before any later phase.
