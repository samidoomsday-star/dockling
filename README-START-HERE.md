# Dockling — start here

This project is being developed in Codex, phase by phase. It is currently a planning starter and Phase 0 Docling exploration, not a finished converter.

## What you need to do now
Nothing to install or configure on your laptop. Codex will explore using fake statements and report what works. No API key is needed for Phase 0.

## Where to look
- `docs/PROGRESS.md`: current phase and next action.
- `docs/EXPLORATION_REPORT.md`: measured results, limitations and outstanding Windows checks.
- `docs/SPEC.md`: original phases 0–10 and product requirements.
- `docs/CODEX-PROJECT-PLAN.md`: cloud/GitHub/device workflow and your BYOK requirements.
- `docs/PHASE0-SETUP.md`: reproducible exploration setup (added during Phase 0).

Code and documents will be committed and pushed to GitHub. On another device you will clone the repository, install its dependencies, download local models, and test Windows/Excel behavior. A step-by-step guide will accompany that stage. Keys and client documents never belong in GitHub.

The `.kilo/` files are preserved as historical reference. You do not need Kilo Code. Active instructions are in `AGENTS.md`. Phase 1 must preserve the existing scoped instruction files.
